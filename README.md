# 入庫記録アプリ（モーター）

スマホのカメラで **QRコード・バーコード** を読み取り、モーターの入庫記録を
**№ / 入庫日付 / 型番 / シリアル / 入庫数** の形式で記録するWebアプリ（PWA）です。
実際の手書き台帳と同じ項目・並びで、CSVに書き出してそのまま集計できます。

インストール不要、ブラウザから利用、オフライン対応。

## 記録する項目（手書き台帳と同じ）

| 列 | 内容 | 例 |
|----|------|-----|
| № | 連番（CSV書出時に自動採番） | 1, 2, 3… |
| 入庫日付 | 既定は当日（変更可） | 2026-02-17 |
| 型番 | 製品の型番 | EF-40DTC2-V / KG-90HT03 |
| シリアル | シリアル／製造番号 | 260312002A / SW251114 |
| 入庫数 | 入庫した数（既定1） | 1, 4, 8 |

## 主な機能

- 📷 **QR＋バーコード読み取り** — [ZXing](https://github.com/zxing-js/library) により
  QR / DataMatrix / CODE128 / CODE39 / EAN / ITF などに対応
- 🖊️ **確認して保存** — 読み取り結果を型番・シリアルへ反映し、確認・修正してから保存
- 🔀 **「← 読取」ボタン** — 読み取った値を型番／シリアルの好きな方へ流し込み
- ✍️ **手入力** — QR/バーコードが無い箱でもキーボードで記録
- 📅 **入庫日付は当日を自動セット**、**入庫数は既定1**
- 📋 **記録一覧** — 型番・シリアルで検索、削除
- 📤 **CSV書出** — `№, 入庫日付, 型番, シリアル, 入庫数`（Excelで文字化けしないBOM付き・古い順に採番）
- 💾 端末内保存（localStorage、サーバー送信なし） / 🔌 オフライン動作 / 📲 ホーム画面追加

## 読み取り内容の解釈について

- QR/バーコードに **JSON**（`{"model":"...","serial":"..."}`）や
  **key:value**（`SN:260312002A` 等、`M/C` `S/N` `L/N` などのキーにも対応）が
  入っている場合は、型番・シリアルへ自動で振り分けます。
- 単純な値だけのコード（例: 形名コードのバーコード）の場合は「読取値」に表示し、
  **「← 読取」ボタン**で型番／シリアルの適切な方へ入れられます。
- いずれも保存前に画面で修正できます。実務では
  「型番はバーコード、シリアルは印字文字を手入力」といった併用が現実的です。

## 使い方

カメラAPIは HTTPS（またはlocalhost）が必須です。本リポジトリは GitHub Pages で公開しています。

1. 公開URLをスマホの Chrome / Safari で開く
2. 「カメラ開始」→ カメラを許可
3. QR/バーコードを枠内に合わせる → 型番・シリアルが反映
4. 入庫数・入庫日付を確認して「記録を保存」
5. 「記録一覧」タブで確認・検索、「CSV書出」でエクスポート

Safari/Chromeの共有 →「ホーム画面に追加」でアプリのように使えます（オフライン可）。

### ローカルで試す

```bash
python3 -m http.server 8000
# 実機カメラを使うには HTTPS が必要
```
