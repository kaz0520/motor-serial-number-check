# モーター QR 記録アプリ

スマホのカメラでQRコードを読み取り、モーターの **製品名** と **シリアル番号** を記録するWebアプリ（PWA）です。インストール不要でブラウザから使え、オフラインでも動作します。

## 主な機能

- 📷 **QRスキャン** — スマホの背面カメラでQRコードを読み取り
- 📝 **自動反映＋手直し** — 読み取った内容を製品名・シリアルへ自動振り分け、確認・修正して保存
- ✍️ **手入力** — QRがない場合は手動で記録も可能
- 📋 **記録一覧** — 保存した記録の検索・削除
- 📤 **CSV書き出し** — Excel等で開けるCSVファイルをエクスポート
- 💾 **端末内保存** — データはブラウザ内（localStorage）に保存。サーバー送信なし
- 🔌 **オフライン対応** — Service Workerで一度読み込めば圏外でも動作
- 📲 **ホーム画面追加** — PWAとしてアプリのように使える

## 使い方

HTTPS（またはlocalhost）環境で配信する必要があります（カメラAPIの制約）。

### ローカルで試す

```bash
# 任意の静的サーバーで配信
python3 -m http.server 8000
# → PC/スマホのブラウザで http://<PCのIP>:8000 を開く
```

スマホの実機カメラを使うには HTTPS が必要です。GitHub Pages など HTTPS 対応の
ホスティングに置くのが簡単です。

### GitHub Pages で公開する例

1. このリポジトリの Settings → Pages
2. Branch を対象ブランチ、フォルダを `/ (root)` に設定して保存
3. 発行された `https://<user>.github.io/<repo>/` をスマホで開く

## QRコードの内容について

以下の書式を自動で解釈して製品名・シリアルに振り分けます（いずれも保存前に画面で修正できます）。

| 書式 | 例 |
|------|-----|
| JSON | `{"product":"AC-750W","serial":"SN-000123"}` |
| key:value | `product:AC-750W; serial:SN-000123` |
| 複数行 | 1行目=製品名 / 2行目=シリアル |
| 単一値 | シリアル番号として扱う |

日本語キー（製品名 / 型番 / シリアル / 製造番号 など）にも対応しています。

## 技術構成

- 依存ライブラリ: [jsQR](https://github.com/cozmo/jsQR)（`vendor/jsQR.js` に同梱）
- フレームワーク不使用のバニラ HTML / CSS / JavaScript
- データ保存: ブラウザ localStorage

## ファイル構成

```
index.html      画面
styles.css      スタイル
app.js          スキャン・保存・一覧・CSV書出のロジック

sw.js           Service Worker（オフラインキャッシュ）
icon.svg        アプリアイコン
vendor/jsQR.js  QRデコードライブラリ
```
